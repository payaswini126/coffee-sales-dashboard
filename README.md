Coffee Sales Dashboard

This project contains a detailed Excel-based dashboard for analyzing coffee sales data across countries, customers, and product types.

Contents
- Dashboard: An interactive slicer-based sheet for visual analysis (Excel only).
- TotalSales: Monthly sales breakdown by coffee type.
- CountryBarChart: Bar chart data showing sales by country.
- Top5Customers: Summary of top-performing customers.
- orders: Raw order-level transaction data.
- customers: Customer information including location and loyalty card status.
- products: Coffee product metadata including pricing and profitability.

Use Case
Useful for:
- Data analysis practice
- Dashboard design
- Sales performance tracking
- Customer segmentation
